# 제품 선택과 라이선스

_어떤 플랜을 왜 골라야 하는지, 쓴 만큼 어떻게 확인하는지 다룹니다. GH-100 모듈 3 실습입니다._

## 이 실습은

- **대상**: 조직에 GitHub 을 도입하거나 비용을 관리해야 하는 사람
- **배우는 것**: 계정 종류와 플랜의 차이, 그리고 사용량을 읽는 법
- **만드는 것**: 플랜 선택 근거 문서와, 직접 재서 계산한 Actions 사용량 추정치
- **걸리는 시간**: 15분
- **선행**: [Introduction to GitHub](https://github.com/skills/introduction-to-github)

이 실습에서 하는 일

1. 시나리오를 보고 플랜을 고르고 근거를 적는다
2. 워크플로를 돌려 billable 시간을 재고 월 예상 분을 계산한다
3. 라이선스와 사용량 리포트를 어떻게 읽는지 정리한다
